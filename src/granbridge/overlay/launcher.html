GRANBRIDGE Overlays

OBS Browser Source overlay suite

How to add to OBS: In OBS Studio, add a Browser Source, check Local file, and point it at the overlay file. Size each source to fit your scene (e.g. 1920x1080 for full-canvas overlays). Enable transparent background in the Browser Source properties so only the overlay elements appear over your scene.
