# GRANBRIDGE v0.1.6 — Match options, shareable results, live commentary, spectator chat

A fast follow to v0.1.5 with quality-of-play features.

## New

- **🎚 Multiplayer match options** — the host now picks the start score (301/501/701) and the
  match length (single leg, best of 3, best of 5) right in the lobby, for X01 and Cricket.
- **📋 Shareable results** — when a game finishes (local or online), copy a compact text summary
  to the clipboard or save a PNG result card (winner, legs, three-dart averages).
- **🎙 Live commentary** — the built-in offline commentator is now on by default: key moments
  ("One hundred and eighty!", "Game shot!") appear as broadcast-style captions during play.
  Disable via `GRANBRIDGE_PLUGINS_ENABLED=[]` if you prefer silence.
- **👁💬 Spectators see the chat** — friends watching your match now see both players' chat
  lines live (read-only) under the board.

## Improved

- README fully refreshed for players and self-hosters (the old manual-TURN instructions are gone —
  TURN credentials have been automatic since v0.1.4).
