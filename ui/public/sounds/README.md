# Sound Effect Files

Real sound effects shipped with the app, played by `FilePack`
(`ui/src/sound/FilePack.ts`). If a file here is missing or fails to decode,
that sound falls back automatically to the built-in `SynthPack` synthesiser —
no code change required.

All clips are 100% self-generated by `tools/make_sounds.py` (numpy synthesis:
layered oscillators, shaped-noise crowds, convolution reverb). To tweak a
sound, edit its builder there and rerun:

```
.venv/Scripts/python tools/make_sounds.py
```

## Filenames

These paths come from `ui/src/sound/manifest.ts` (`SOUND_MANIFEST`):

| File | Sound event | Budget |
|------|-------------|--------|
| `hit.mp3`                | Regular dart hit (single / double) | < 3 s |
| `hit-treble.mp3`         | Treble hit | < 3 s |
| `hit-bull.mp3`           | Bullseye hit | < 3 s |
| `miss.mp3`               | Dart misses the board | < 3 s |
| `bust.mp3`               | Player busts | < 3 s |
| `leg-won.mp3`            | Player wins a leg | < 3.5 s |
| `game-won.mp3`           | Player wins the game | < 4.5 s |
| `one-eighty.mp3`         | 180 scored in a single visit | < 3.5 s |
| `checkout-available.mp3` | Checkout route becomes available | < 3 s |

Mid-game cues stay short so they never overlap the next throw; win fanfares
get extra room for their reverb tail.

## Replacing a sound

Drop any MP3 at the same path — Vite serves `ui/public/` at the site root
with no hashing, so replacements take effect on next load.

Recommended specs: 44.1 kHz, MP3 128 kbps+, within the duration budget above.
